## Lambda Proxy Integration

### Without Proxy Integration

API Gateway controls request format.

Example

```js
event = {
  name: "Pen",
  quantity: 10,
};
```

Problems

- Inconsistent payload
- Query parameters may not be available
- Request body may already be parsed
- Different methods behave differently

---

### With Lambda Proxy Integration (Recommended)

Lambda receives complete HTTP request.

Example

```js
event = {
  body,
  headers,
  pathParameters,
  queryStringParameters,
  httpMethod,
  resource,
};
```

Benefits

- Consistent request format
- Easier debugging
- Recommended by AWS
- Same structure for every API

# 5. Challenges Faced, Root Cause and Solutions

---

## 1. aws-sdk package not found

### Error

```
Cannot find package 'aws-sdk'
```

### Root Cause

Node.js 18 no longer bundles AWS SDK v2.

### Solution

Migrated to AWS SDK v3.

---

## 2. event.body undefined

### Root Cause

Lambda was receiving different payload structures because Proxy Integration was disabled.

### Solution

Enabled Lambda Proxy Integration.

---

## 3. Only id stored in DynamoDB

### Root Cause

Request body fields became undefined.

DocumentClient ignores undefined attributes.

### Solution

Fixed request parsing.

---

## 4. POST returned only id

### Root Cause

Lambda response returned only id.

### Solution

Returned complete object.

---

## 5. GET returned escaped JSON

### Root Cause

Lambda Proxy Integration requires body to be string.

### Solution

Used

```js
JSON.stringify(...)
```

This is expected behaviour.

---

## 6. GET Details returned all records

### Root Cause

Lambda Proxy Integration was disabled.

Query parameters were unavailable.

Lambda always executed

```
ScanCommand
```

instead of

```
GetCommand
```

### Solution

Enabled Lambda Proxy Integration.

---

## 7. DELETE returned "id is required"

### Root Cause

Path parameter wasn't reaching Lambda due to API Gateway configuration.

### Solution

Verified

```
/item/{id}
```

Enabled Proxy Integration.

---

## 8. UPDATE returned "id is required"

### Root Cause

Query parameter wasn't consistently reaching Lambda.

### Solution

Verified URL

```
PUT /item?id=<id>
```

Enabled Proxy Integration.

---

## 9. Confusion between PutCommand and PutItem

### Root Cause

AWS SDK v3 uses Command Pattern.

### Solution

Learned mapping

```
PutCommand    → PutItem
GetCommand    → GetItem
UpdateCommand → UpdateItem
DeleteCommand → DeleteItem
ScanCommand   → Scan
```

## 6.1 Create Item — `create-item`

### API

POST /item

### DynamoDB Operation

PutCommand → PutItem

### Implementation

```javascript
import { DynamoDBClient } from "@aws-sdk/client-dynamodb";
import { DynamoDBDocumentClient, PutCommand } from "@aws-sdk/lib-dynamodb";

const client = new DynamoDBClient({});
const dynamo = DynamoDBDocumentClient.from(client);

export const handler = async (event) => {
  try {
    const body =
      typeof event.body === "string" ? JSON.parse(event.body) : event.body;

    if (
      body.name === undefined ||
      body.rate === undefined ||
      body.quantity === undefined ||
      body.isAvailable === undefined
    ) {
      return {
        statusCode: 400,
        body: JSON.stringify({
          error: "Missing required fields",
        }),
      };
    }

    const item = {
      id: Date.now().toString(),
      name: body.name,
      rate: body.rate,
      quantity: body.quantity,
      isAvailable: body.isAvailable,
    };

    await dynamo.send(
      new PutCommand({
        TableName: process.env.TABLE_NAME,
        Item: item,
      }),
    );

    return {
      statusCode: 201,
      headers: {
        "Content-Type": "application/json",
      },
      body: JSON.stringify(item),
    };
  } catch (error) {
    console.error(error);

    return {
      statusCode: 500,
      body: JSON.stringify({
        error: error.message,
      }),
    };
  }
};
```

## 6.2 Get Items / Get Details — `get-items`

The same Lambda handles both:

```text
GET /item
```

and

```text
GET /item?id={id}
```

### DynamoDB Operations

```text
GET /item
    ↓
ScanCommand → Scan

GET /item?id={id}
    ↓
GetCommand → GetItem
```

### Implementation

```javascript
import { DynamoDBClient } from "@aws-sdk/client-dynamodb";
import {
  DynamoDBDocumentClient,
  ScanCommand,
  GetCommand,
} from "@aws-sdk/lib-dynamodb";

const client = new DynamoDBClient({});
const dynamo = DynamoDBDocumentClient.from(client);

export const handler = async (event) => {
  try {
    const id = event.queryStringParameters?.id;

    // GET DETAILS
    if (id) {
      const result = await dynamo.send(
        new GetCommand({
          TableName: process.env.TABLE_NAME,
          Key: {
            id: id,
          },
        }),
      );

      return {
        statusCode: 200,
        headers: {
          "Content-Type": "application/json",
        },
        body: JSON.stringify(result.Item || {}),
      };
    }

    // GET ALL
    const result = await dynamo.send(
      new ScanCommand({
        TableName: process.env.TABLE_NAME,
      }),
    );

    return {
      statusCode: 200,
      headers: {
        "Content-Type": "application/json",
      },
      body: JSON.stringify(result.Items || []),
    };
  } catch (error) {
    console.error(error);

    return {
      statusCode: 500,
      body: JSON.stringify({
        error: error.message,
      }),
    };
  }
};
```

## 6.3 Update Item — `update-item`

### API

```text
PUT /item?id={id}
```

### Request

ID is passed as a query parameter.

Updated data is passed in the request body.

Example:

```json
{
  "name": "Blue Pen",
  "rate": 12,
  "quantity": 30,
  "isAvailable": false
}
```

### DynamoDB Operation

```text
UpdateCommand → UpdateItem
```

### Implementation

```javascript
import { DynamoDBClient } from "@aws-sdk/client-dynamodb";
import { DynamoDBDocumentClient, UpdateCommand } from "@aws-sdk/lib-dynamodb";

const client = new DynamoDBClient({});
const dynamo = DynamoDBDocumentClient.from(client);

export const handler = async (event) => {
  try {
    const id = event.queryStringParameters?.id;

    if (!id) {
      return {
        statusCode: 400,
        body: JSON.stringify({
          error: "id is required",
        }),
      };
    }

    const body =
      typeof event.body === "string" ? JSON.parse(event.body) : event.body;

    const result = await dynamo.send(
      new UpdateCommand({
        TableName: process.env.TABLE_NAME,

        Key: {
          id: id,
        },

        UpdateExpression: `
          SET #name = :name,
              rate = :rate,
              quantity = :quantity,
              isAvailable = :isAvailable
        `,

        ExpressionAttributeNames: {
          "#name": "name",
        },

        ExpressionAttributeValues: {
          ":name": body.name,
          ":rate": body.rate,
          ":quantity": body.quantity,
          ":isAvailable": body.isAvailable,
        },

        ReturnValues: "ALL_NEW",
      }),
    );

    return {
      statusCode: 200,
      headers: {
        "Content-Type": "application/json",
      },
      body: JSON.stringify(result.Attributes),
    };
  } catch (error) {
    console.error(error);

    return {
      statusCode: 500,
      body: JSON.stringify({
        error: error.message,
      }),
    };
  }
};
```

## 6.4 Delete Item — `delete-item`

### API

```text
DELETE /item/{id}
```

### Request

ID is passed as a path parameter.

Example:

```text
DELETE /item/123
```

### DynamoDB Operation

```text
DeleteCommand → DeleteItem
```

### Implementation

```javascript
import { DynamoDBClient } from "@aws-sdk/client-dynamodb";
import { DynamoDBDocumentClient, DeleteCommand } from "@aws-sdk/lib-dynamodb";

const client = new DynamoDBClient({});
const dynamo = DynamoDBDocumentClient.from(client);

export const handler = async (event) => {
  try {
    const id = event.pathParameters?.id;

    if (!id) {
      return {
        statusCode: 400,
        body: JSON.stringify({
          error: "id is required",
        }),
      };
    }

    await dynamo.send(
      new DeleteCommand({
        TableName: process.env.TABLE_NAME,

        Key: {
          id: id,
        },
      }),
    );

    return {
      statusCode: 200,
      headers: {
        "Content-Type": "application/json",
      },
      body: JSON.stringify({
        message: "Item deleted",
      }),
    };
  } catch (error) {
    console.error(error);

    return {
      statusCode: 500,
      body: JSON.stringify({
        error: error.message,
      }),
    };
  }
};
```

# 8. Important Code Patterns

## DynamoDB Client

```javascript
const client = new DynamoDBClient({});
const dynamo = DynamoDBDocumentClient.from(client);
```

Creates the DynamoDB client and wraps it with the Document Client.

---

## Environment Variable

```javascript

```

The actual value is:

```text
TABLE_NAME = Items
```

---

## Sending a DynamoDB Command

```javascript
await dynamo.send(
  new PutCommand({
    TableName: process.env.TABLE_NAME,
    Item: item,
  }),
);
```

General pattern:

```text
dynamo.send(
    new SomeCommand(parameters)
)
```

---

## Query Parameter

```text
GET /item?id=123
```


---

## Path Parameter

For:

```text
DELETE /item/123
```

```javascript

```

---

## Request Body

With Lambda Proxy Integration:

```javascript
event.body;
```

It can be handled as:

```javascript
const body =
  typeof event.body === "string" ? JSON.parse(event.body) : event.body;
```

---

```javascript
return {
```

The response `body` is converted to a string because Lambda Proxy Integration expects the body in string format.
