PRACTICAL LIST

DOCKER

1] Beginner:

- Start docker desktop. Check basic commands. Pull and run hello-world image. Then stop and remove it.
- Pull an image and run a container. Do port mapping.
- Open interactive terminal inside a container

2] Bind mounting

3] Docker volume

- Create a docker volume. Add some data. Stop and start container and verify if data persists

4] Docker network

- Create a docker network and connect the containers to that network

5] DockerFile

- Create a custom docker image from docker file.

KUBERNETES

1] Start Kubernetes cluster with minikube and verify commands from kubectl

2] Create a deployment through CLI and deploy a container

3] Create a service through CLI and expose the deployment to browser

4] Delete and recreate Pods

5] Create deployment and service through a YAML file
